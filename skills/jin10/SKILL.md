# 金十数据（Jin10）Skill

通过金十数据 MCP 服务获取实时行情报价、财经快讯和深度资讯，帮助用户构建金融市场分析工具或 Agent。

## 可用工具概览

金十数据 MCP 提供以下工具：

| 工具名 | 用途 | 典型场景 |
|---|---|---|
| `get_quote` | 获取指定品种最新行情报价 | 查黄金价格、看美元指数涨跌 |
| `list_flash` | 获取最新快讯列表 | 浏览今日财经要闻 |
| `search_flash` | 按关键词搜索快讯 | 搜索"美联储"相关快讯 |
| `list_news` | 获取最新资讯文章列表 | 浏览深度分析文章 |
| `search_news` | 按关键词搜索资讯 | 搜索"原油"相关分析 |
| `get_news` | 获取单篇资讯详情 | 阅读某篇文章全文 |
| `list_calendar` | 获取财经日历数据 | 查看今日经济数据发布日程 |

## 工具调用指南

### 1. 行情报价 — `get_quote`

获取指定品种的最新价格、开盘价、最高价、最低价、成交量及涨跌幅。

**调用签名：** `get_quote({ code })`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | string | 是 | 品种代码 |

常用品种代码如下：

| 品种 | 代码 |
|---|---|
| 现货黄金 | `XAUUSD` |
| 现货白银 | `XAGUSD` |
| 美元指数 | `DINIW` |
| 欧元/美元 | `EURUSD` |
| 英镑/美元 | `GBPUSD` |
| 美元/日元 | `USDJPY` |
| WTI原油 | `USOIL` |
| 布伦特原油 | `UKOIL` |
| 上证指数 | `000001` |
| 标普500 | `SPX` |
| 纳斯达克 | `IXIC` |
| 道琼斯 | `DJI` |
| BTC/USD | `BTCUSD` |

如果用户提到的品种不在上表，尝试用合理的代码调用，或提示用户确认品种代码。

**响应字段说明：**

```
data.code          — 品种代码
data.name          — 品种中文名
data.time          — 行情时间（ISO 8601）
data.open          — 开盘价
data.close         — 最新价（收盘价）
data.high          — 最高价
data.low           — 最低价
data.volume        — 成交量
data.ups_price     — 涨跌额
data.ups_percent   — 涨跌幅（百分比）
```

**呈现格式示例：**

> **现货黄金（XAUUSD）**
> 最新价：2115.30 | 涨跌：+14.80（+0.70%）
> 今开：2100.50 | 最高：2120.00 | 最低：2095.00
> 成交量：125,000

### 2. 快讯 — `list_flash` / `search_flash`

快讯是金十 7x24 小时滚动播报的短消息，涵盖突发新闻、数据公布、机构观点等。

- **`list_flash({ cursor? })`**：获取最新快讯，支持翻页。
- **`search_flash({ keyword })`**：按关键词搜索快讯。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keyword` | string | `search_flash` 必填 | 搜索关键词 |
| `cursor` | string | 否 | 翻页游标，传入上次响应的 `next_offset` 值 |

**响应字段说明：**

```
data.items[].id       — 快讯 ID
data.items[].content  — 快讯正文（通常以【标题】开头）
data.items[].time     — 发布时间
data.items[].url      — 快讯详情链接
data.next_offset      — 下一页偏移量（用于翻页）
data.has_more         — 是否有更多数据
```

**呈现格式示例：**

> **13:41** — 日元贬值导致橙子价格过高…  [详情](https://flash.jin10.com/detail/xxx)

展示快讯时，按时间倒序排列，提取关键信息，附上详情链接。如果用户要求更多，使用 `next_offset` 翻页。

### 3. 资讯 — `list_news` / `search_news` / `get_news`

资讯是深度财经文章与分析评论，适合了解市场趋势和专业解读。

- **`list_news({ cursor? })`**：获取最新资讯列表。
- **`search_news({ keyword, cursor? })`**：按关键词搜索资讯。
- **`get_news({ id })`**：根据文章 ID 获取单篇资讯的完整内容。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `keyword` | string | `search_news` 必填 | 搜索关键词 |
| `cursor` | string | 否 | 翻页游标，传入上次响应的 `next_offset` 值 |
| `id` | string | `get_news` 必填 | 文章 ID，从列表响应的 `data.items[].id` 获取 |

**响应字段说明（列表）：**

```
data.items[].id            — 文章 ID（用于 get_news 获取全文）
data.items[].title         — 文章标题
data.items[].introduction  — 文章摘要
data.items[].time          — 发布时间
data.items[].url           — 文章链接
data.next_offset           — 下一页偏移量
data.has_more              — 是否有更多数据
```

**呈现格式示例：**

> **市场主线从"避险交易"转向"能源供给驱动交易"**
> 原油高位表现还能持续多久…
> 2026-03-27 16:29 | [阅读全文](https://xnews.jin10.com/details/214768)

展示资讯时列出标题、摘要和链接。如果用户对某篇感兴趣，用 `get_news` 获取全文并进行总结或分析。

### 4. 财经日历 — `list_calendar`

获取财经日历数据，包含经济数据发布日程、重要事件等。

**调用签名：** `list_calendar({})`

无需传入参数，直接调用即可获取财经日历数据。

适用场景：用户问"今天有什么重要数据公布"、"本周财经日历"、"接下来有哪些经济事件"等。

## 典型工作流

### 市场概览

当用户问"今天市场怎么样"或"给我看看行情"时：
1. 调用 `get_quote` 获取几个核心品种（如 XAUUSD、EURUSD、USOIL、SPX）的行情
2. 调用 `list_flash` 获取最新快讯
3. 综合行情数据和快讯，给出简要的市场概览

### 专题分析

当用户关注某个特定话题时（如"美联储加息"）：
1. 调用 `search_flash` 和 `search_news` 搜索相关内容
2. 调用相关品种的 `get_quote`（如美元指数、黄金）
3. 如发现有价值的深度文章，用 `get_news` 获取全文
4. 结合行情和资讯，提供专题分析

### 品种追踪

当用户持续关注某个品种时：
1. 调用 `get_quote` 获取最新行情
2. 调用 `search_flash` 搜索该品种相关快讯
3. 给出价格走势总结及近期影响因素

## 注意事项

- 行情数据有时间属性，向用户展示时注明数据时间，避免误导。
- 快讯内容通常以 `【主题】` 开头，展示时可提取主题作为标题。
- 翻页时使用响应中的 `next_offset` 值，不要自行构造。
- 当 `has_more` 为 `false` 时，不再尝试翻页。
- 所有价格数据为字符串类型，如需计算先转换为数值。

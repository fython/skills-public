# 努努平面图转 Blender 模型

## 确认建模依据

- 读取原平面图、已有模型和用户修订要求。参考实物用于校准外观、姿态与层次，不能拿照片投影到任意球体上冒充纸样建模。
- 按 [交接约定](references/pattern-contract.md) 建立部件和连接清单；上游没有清单时从原图补建，标明推定。缺少尺度时使用明确的相对尺度，不能声称准确实物尺寸。
- 区分外观近似模型与布料缝合仿真。仅有印花图时通常先做前者；有缝线、材料数据和可靠配对后才承诺更接近真实的缝合/填充求解。
- 保留来源路径、页码/区域、源轮廓、正反面图案与变形参数。不要把一次项目中的坐标、头身比、伸缩率或内存设置写成所有努努的默认值。

## 1. 从图稿提取部件

1. 从 PDF/原图取得清晰、未改变比例的图稿；检查坐标轴、分辨率、镜像和颜色。展示图的裁切边、印花外沿、净缝线与缝份外沿必须区分。
2. 优先采用已有矢量路径；对光栅进行分区、轮廓提取和人工核对。不要让背景、阴影、印花内部白色或标注线污染轮廓。
3. 保留二维参数坐标与 UV 对应关系，再生成网格。区分纹理参考平面与可填充封闭部件。
4. 对正反面不同形状的图案，通过方向、对位点和轮廓匹配建立对应；简单平移/镜像或按扫描行重映射只能作经检查的近似。逐面检查边缘漏白、反向与图案变形。
5. 查看一体纸样是否已经包含腿和裆部，不另造独立椭球脚来补视觉体积。

## 2. 先构建填棉素体

- 用净缝线确定边界和前后片配对，再用曲面鼓起或缝合仿真形成头、身体和四肢；用省道、接缝与填充程度解释体积。不要先堆任意球体再贴图。
- 对外观近似模型，允许参数化鼓起和局部修形，但保留纸样对应并标注未经物理校准。柔软布料有一定伸缩不意味着可以无限伸展；形态键也不是材料仿真。
- 按装配关系完成肩、腕、腿根和头身连接。可采用连续闭合素体，也可采用有明确缝合边界/约束的分体结构。
- `Join`、父子关系、物体相交或命名为“已缝合”都不能单独证明连接正确。若选择连续素体，检查实际连通性和闭合性；若选择分体缝合，检查边界配对、间距、固定关系与姿态变化后的连续性。
- 体素重网格仅用于适当的填棉核心；保留原 UV 表面或建立可追溯转移，避免破坏原图。不要将头发和衣服一起重网格成实心体。

## 3. 装配无填充布片

- 默认将头发、服装和多数配饰建成薄表面；只有用户/纸样明确要求时才增加填充。用弯曲、折叠、叠层和少量布厚表达体积。
- 按设计装配后脑发套、底层刘海、两侧覆盖片、主刘海、鬓发、双辫和发饰；给根部固定区与自由边分别定义顶点组。
- 给每个可见反面明确材质与 UV。双辫反面有印花时用对应反面稿，不能让 Solidify 的反面材料默认为纯色而遗漏图案。
- 使用 Shrinkwrap 等贴合工具时控制目标、方向、偏移和影响区域；它们不能自动判断层序、覆盖完整性或缝合关系。检查是否吸到错误一侧、穿入下层、造成白边或褶皱塌陷。
- 将围裙、领口和贴饰定位到支持它们的身体/衣服曲面；让裙摆、花边及蝴蝶结按折叠产生形态。避免浮空围裙、过硬直筒裙或没有收束的平摊蝴蝶结。
- 保持主图案的遮挡逻辑。底层出现重复雪花等问题时，先查部件识别和装配，不直接删除图案或扩大主片掩盖问题。

## 4. 分开调整头型与露脸窗口

先阅读 [头发与头型修正](references/head-and-hair.md)。至少分别控制：头顶/后脑轮廓、脸部轮廓、五官地标、刘海下缘、侧发内缘、头身连接。

- 减少露脸面积时，先调整刘海下缘、侧发内缘和底层覆盖，不整体压矮头部。
- 增加头高时，固定五官、下巴、头身连接和已认可的露脸边界，局部抬高头顶/后脑上半部；同步贴合发片上缘与头饰。
- 区分几何位移与材料拉伸。让发片弯曲、重新定位或调整接缝来获得覆盖；若固定纸样确实不足以包覆目标头型，应回到平面稿修订或降低填充，不强行拉长。
- 修改后用相同相机和尺度复查固定地标、头顶高度、侧脸暴露范围以及图案畸变。禁止只看正面就宣布装配通过。

## 5. 校准与渲染

1. 先用低成本纯色/材质预览确认轮廓和装配，再上原图 UV 与布料微表面。先解决结构，后增加毛绒细节。
2. 将实物和模型调整到可比较的尺度与视角；区分光照/白平衡、拍摄透视和手持挤压与真正的比例差异。
3. 导出正面、两侧或至少一侧、斜侧面、背面及隐藏衣服/头发的素体。按任务增加近景或另一侧，不能用未经渲染的旧图冒充新版。
4. 缺少实物背面时，把背面作为结构检查和推定结果展示，不声称已还原真实背面。
5. 使用安装环境实际支持的 Blender 渲染功能。先做一个小预览；粒子毛发、贴图尺寸、线程数、采样数和分辨率按资源状况调整。内存不足时查日志、降低非关键开销并用独立进程逐视角渲染；不要反复重跑同一失败配置。
6. 保留原始高分辨率贴图；如需较小嵌入副本，记录它是渲染优化，不覆盖唯一原稿。不要编造去噪器或版本功能可用性。

## 6. 验收与交付

- 用 [验收与故障定位](references/validation.md) 逐项检查来源、几何、正反面 UV、层序、固定地标及多视角；根据模型类型选择拓扑标准。
- 可运行 `scripts/audit_blend.py` 收集原始网格证据：
  `blender -b model.blend -t 1 --python <skill>/scripts/audit_blend.py -- --output audit.json`
  该报告不评估修改器后的连接，也不验证真实缝制、碰撞或外观；必须与可视检查结合。
- 交付 `.blend`、打包贴图/重建脚本、最新版预览、部件来源与假设，以及必要的检查结果。打开工程所需的依赖必须包含或明确说明。
- 保留可编辑部件、UV 和关键形变控制；报告已修复项及仍存在的限制。只完成近似外观时不要宣称完成材料仿真或生产验证。

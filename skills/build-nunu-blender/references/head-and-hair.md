# 头型、露脸窗口与发片包覆

## 建立相互独立的地标

- 头部：头顶、后脑最高点/最深点、左右最宽处、下巴、颈部连接。
- 脸部：眼线、眼角、嘴、脸颊特征点；不要混淆纹理地标和几何顶点。
- 头发：刘海下缘、侧发内缘、头顶固定线、双辫根部和自由端。

固定已认可的地标，只修改本轮问题相关的控制量。相机变化后不能直接拿截图像素差冒充形变误差。

## 局部增高，同时维持小露脸区域

1. 保存修改前地标、源网格/UV 和同相机预览。
2. 设置保护区，包含五官、下巴、颈部以及刘海下缘/侧发内缘。以顶点组或晶格控制权重，不依赖一个适用于所有角色的固定高度阈值。
3. 对头顶/后脑上半部施加平滑递增位移，例如 `z' = z + Δh * smoothstep(t)`。`t` 根据本模型的保护区上界和冠部范围归一化，保护区权重为零。必要时用二维/三维权重区分前额与后脑。
4. 对发套、发片上缘与头饰使用协调的包覆/定位，保持固定的下缘。独立发片优先通过弯曲和重定位适配；共享位移只是一种几何近似，不自动保证布料长度可行。
5. 记录保护区位移、缝线配对长度变化和需要的伸长；如有材料实测数据，再与其比较。无数据时只报告几何变化与未验证状态，不能把常数百分比称为真实伸缩极限。
6. 检查头顶与侧面的覆盖、缝隙、根部连接和图案拉长；需要时回到纸样修改，而不是继续增大 Shrinkwrap 偏移。

## 常见现象与排查

| 现象 | 先检查 | 正确处理方向 |
|---|---|---|
| 侧脸露得多 | 底层发套是否只到后脑，侧发内缘是否过后 | 先调整侧面覆盖片的包覆和层序，不先改头顶高度 |
| 头扁、横向显宽 | 是否曾整体压缩头高，头顶轮廓是否不足 | 局部抬升冠部，保持已认可的脸和连接 |
| 头变高后脸也变长 | 五官和刘海下缘是否被一起拉伸 | 固定脸部地标，将冠部形变隔离 |
| 头发像头盔 | 是否靠厚度/填充做发量，层间边界是否消失 | 恢复薄片、自由边和真实叠层；先修形再改材质 |
| 重复图案过多 | 是否用了错误部件/朝向，底片是否应被遮住 | 按来源检查，重新装配；不要无依据改绘原图 |
| 正面正常、侧面悬空 | 是否只有前向投影贴合，根部是否没固定 | 查侧面厚度、包覆和固定边，补真实连接 |

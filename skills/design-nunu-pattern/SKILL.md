# 努努平面图设计

## 先确定输入和交付等级

- 阅读用户提供的图、PDF、纸样、现有模型与修订要求；记录能实际看到的内容。缺图时先找已授权文件，无法取得再请求补充，不凭文件名编造细节。
- 区分三种交付：角色外观设定、分部件印花图、带尺寸和缝合关系的制作纸样。按请求完成；尺寸或缝法不足时标为待打样，不能把外观图称为可直接投产纸样。
- 优先沿用用户已确定的尺寸、风格、材料和工艺。仅对影响可制作性的缺失信息提问；可逆的外观选择先做合理方案并标注假设。
- 把照片中的透视、手部挤压、摆放姿态和光照与真实形状分开。正面照片只能可靠约束部分投影，不能据此确定后脑厚度或背面缝法。
- 区分直接观察、笔记转述、设计推定与待确认项；记录来源与实际核查范围，不把他人的视频抽查记录写成自己已观看或作者的通用结论。
- 记录底版和素材的来源、使用范围及许可状态。公开附件只采用有设计记录的独立原创素材或许可明确覆盖相应用途的素材；免费、自用或允许手作接单不等于允许再分发。许可未知时不自动下载、描摹或打包为公开附件。

## 选择参考分支

### A. 已有努努可参考

使用内置的无大月牙努努图纸时，先阅读 [无大月牙底版使用说明](references/no-large-crescent-base.md)，再从 `assets/no-large-crescent/` 中选择 `tinted-2x.webp`（浅底色版）或 `white-2x.webp`（白底版）。两张图为同一套底版的不同底色呈现，设计时二选一；先缝合已确认的省道，再进行后续部件拼接。提高图片像素数不代表已校准成品尺寸或已完成试缝。

1. 确认参考属于实物、3D 模型、原平面稿还是它们的组合。对已有 3D 模型检查多视角和对象结构；不要把旧模型的错误当成设计依据。
2. 测量归一化比例：总高、头高/头宽、头身比、露出脸部的宽高、眼线、下巴、肩宽、手脚露出量、辫子与裙摆范围。统一尺度和相机条件后再比较，不从透视照片直接抄像素为毫米。
3. 提取可复用结构与需更换的角色特征。保留成熟素体或纸样时，核对新发型、配饰与衣服是否仍能装配。
4. 标出所有实物证据与推定部分，尤其是后脑、发片反面、夹层和被衣服遮住的连接。

### B. 没有努努参考，只有其他风格角色

1. 先阅读 [角色转译方法](references/character-translation.md)，提炼辨识特征，再做努努外观设定；不要直接把长身立绘拆成布片。
2. 保留发色分区、刘海走势、眼型/眼色、代表性配饰和服装色块。将长细肢体、尖角、复杂衣褶转成短圆体块、刺绣/印花或独立薄布配饰。
3. 先定义努努素体与工艺假设，再画正面设定和必要侧面/背面。没有可靠样品时，用可调的比例草案，不宣称存在统一必用头身比。
4. 在身份特征与可制作性之间取舍，说明删减、合并和改为印花的细节。用户未要求多方案时先完成一个连贯方案。
5. 把这一轮得到的努努设定作为后续参考，再进入 A 的比例和部件分析。实物试样与用户反馈可回写设定；概念图的背面不是实物证据。

## 建立共同的结构逻辑

- 默认仅头部、躯干和四肢填棉；头发、服装、蝴蝶结及多数配饰为无填充布片。用户明确指定的例外单独记录。
- 分别控制头部外轮廓与“露脸窗口”。头顶高、刘海低可以同时成立；不能靠压矮整个头来减少露脸面积。
- 给头发分层：后脑/底层发套 → 基础刘海与侧发 → 主刘海/卷曲鬓发 → 双辫 → 发饰。实际层序依据设计调整，并画清根部固定位置与遮挡。
- 把脸侧覆盖、头顶覆盖与后脑覆盖分别检查。少数卷曲鬓发不能替代耳侧的大块底层覆盖。
- 把每个部件对应到来源、正反面、填充状态、连接对象与装配顺序。用 [交接约定](references/pattern-contract.md)，需要时复制 `assets/pattern-manifest.template.json` 并填实。

## 先选发片工艺

- 为每个发片记录工艺、层数、材料、边缘处理和根部固定方式；无填充不等于单层，也不等于必须胶合。
- 胶合薄片：明确两层正反与毛向，先稳定贴合和大轮廓，再修细发尖；按所选材料和胶合方式确定边缘留量，不套用缝合翻面的缝份。
- 缝合翻面：明确配对缝线、缝份、返口和翻面顺序；检查细尖与窄连接能否翻出，未填棉也需要这些结构信息。
- 热粘合：先确认材料组合与处理条件，再决定操作顺序和边缘处理；不能把某次喷水、隔布或熨烫示范推广到所有印花绒布。
- 在边角料上检查适用的粘合强度、渗胶、掉色、绒毛受热和手感，记录条件与结果。未经验证不指定通用胶水型号、温度、留量或伸缩率；不同工艺可用于不同部件，不能无说明混成一套步骤。

## 绘制平面图

1. 先画素体缝合结构，确认大轮廓和覆盖关系，再放置印花和装饰。素体、五官、刘海、侧发、后发和饰品分别管理；修改刘海不连带拉伸五官，修改头高或头宽后重新核对五官定位、发片贴合和固定位置。保留原纸样的腿、裆部等一体结构，避免重复增加已包含的部件。
2. 将外观轮廓、净缝线、裁切线、缝份、折线、省道、对位点、返口和填棉口放在独立且可区分的图层。没有工艺依据时不要自行宣称固定缝份值。
3. 在净缝线之间核对缝合长度、方向、对位点和预定吃势；有意差量单独标明。检查左右件、镜像件、布面朝向、数量、毛向及布料伸缩方向。毛向与伸缩方向分别标记；有方向要求的裁片不能为省布任意旋转，双层发片应分别核对两层方向。
4. 沿缝线预留五官与关键图案的安全区域；将填充后的弧面变形纳入预览。不要将眼睛或雪花跨缝移位后仅凭平面图判断正常。
5. 分别绘制或明确指定正反面图案。对不对称双辫、文字、徽记等记录翻面与镜像规则，不能默认反面是纯色或复用正面。
6. 保留完整发片轮廓并画装配示意：哪里被遮住、哪里自由垂落、哪里折叠。用实际叠层隐藏多余底片花纹，不删除来源证据来掩盖装配问题。
7. 精确纸样与尺寸图使用可编辑矢量/几何绘制；AI 生成的角色效果图只能作为外观参考。印花图与制作纸样都需标明实际输出尺寸、页面或布面尺寸和打印比例；印花光栅按真实打印尺寸检查分辨率。嵌入可实测的校准标记并注明 100% 打印；更换纸张尺寸时采用保持比例的排版或分页，不能自动缩到 A4 后仍称原尺寸。
8. 若用了图像生成辅助，遵守当前可用图像工具的使用要求，并将概念图与尺寸约束的纸样分开交付。

## 检查与交付

- 将平面部件重新组合成正面示意，核对角色特征、图案位置、露脸范围和发片遮挡；侧面检查脸侧，背面检查后发，顶视检查头顶空隙。没有参考的视角标明推定，未检查的视角保留为待验证；必要时用简单 3D/纸模验证包覆。
- 按连接关系核对肩部、手腕、腿根、头身连接；区分缝合、夹缝、表面固定与自由边。
- 检查每个可见面是否有正确印花、细小配饰是否可制作、发片能否覆盖弧面。不能靠无限拉伸解决覆盖不足。
- 按交付等级提供可编辑源文件、清晰预览及所需部件清单、装配示意与待验证项。印花图须附输出尺寸与打印校准信息；制作纸样另按工艺提供缝份、配对缝线、返口等，明确原图是否已含缝份。不适用与未知分开记录。
- 制作纸样的验证状态独立于交付等级；尺寸齐全不代表已试缝。未经实样验证的新版本标为试作版，不承诺成品比例。新素体、陌生面料或复杂包覆应实物打样，3D 效果图不能替代它。
- 用与正式材料伸缩特性相近的布料优先试缝头部，记录纸样版本、缝份处理、材料方向、填充情况及成品头宽、头高、眼距、下巴和覆盖情况。先区分结构、填充与遮挡问题，再改对应部件；每轮尽量只改一类主要变量，保留前后对照。结构、尺寸、材料或工艺改变后，受影响的检查须重做，旧样通过不能自动沿用到新版本。
- 若用户继续要求 3D，交接给 `$build-nunu-blender`，携带原稿、部件对应关系、尺度依据和假设，而不只给一张合成效果图。

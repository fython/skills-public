# 从其他风格角色转成努努

## 转译顺序

1. 列出 3–5 个不可丢失的识别特征，以及可简化的细节。优先轮廓、发型分区、五官组合和配色；不要只靠服装图案辨识角色。
2. 确定面向实物工艺的表达：填棉体块、无填充贴片、刺绣、印花、折叠布件。不要把所有视觉凸起都解释为填棉。
3. 在正面小尺寸缩略图中验证辨识度，再补侧面厚度与背面推定。用相同素体评估改动，避免每轮同时变头型、眼位和衣装。
4. 先建立能装配的努努设定，再展开部件；复杂发型允许改成数层可定位布片，而不是逐根头发立体化。

| 原角色信息 | 努努表达方式 | 检查点 |
|---|---|---|
| 细长体型与姿态 | 短圆素体；少量姿态通过缝合角度表达 | 四肢是否仍连到躯干，重心是否合理 |
| 发量与尖发束 | 底层覆盖片加少数特征发片，边缘弯折 | 从侧面看是否露出过多脸侧，薄片是否被误做成充气体 |
| 大量衣褶、金属件 | 合并色块；选择印花、刺绣或少量薄布配件 | 尺寸下能否辨认及加工，不把必要结构仅画在贴图上 |
| 锐利眼神或成熟脸型 | 保留眼型关系和眉眼方向，适配短脸 | 不无条件放大眼睛或改变表情 |
| 硬盔甲、帽子、兽耳 | 单独判断支撑、衬里、折叠或填充 | 不套用“所有配件无填充”的绝对规则 |

## 外观设定的最低信息

给出整体轮廓、露脸窗口、五官定位、主要色块、发片层序、配饰位置、身体和四肢结构。后脑厚度、不可见服装细节和背面花纹若无证据，标为设计选择。角色原图的阴影不是纸样分界；插画的夸张透视不是制作尺寸。

## 反馈的定位方式

- “不像本人/角色”：先核对识别特征，不首先增加毛绒渲染。
- “脸大”：区分头太大、露脸太宽、脸露得太高、五官太小，分别处理。
- “头扁但脸不能变大”：增加头顶轮廓，固定刘海下缘、侧发内缘、五官和下巴。
- “看上去硬”：先检查轮廓、折叠、缝合受力与层次，再改材质。
